# Licences and data provenance

Solar Map is built from public scientific data and a small number of openly licensed assets. Nothing here is
fetched at runtime: every dataset is downloaded once by a script in `scripts/`, checked, and committed.

## Ephemeris and reference data

| Dataset | Source | Terms |
|---|---|---|
| VSOP87A planetary theory (`src/astro/data/vsop87a.js`) | Bretagnon & Francou 1988, A&A 202, 309; files from the [IMCCE distribution](https://ftp.imcce.fr/pub/ephem/planets/vsop87/) | Freely redistributable; cite the paper. |
| JPL Horizons state vectors (`test/fixtures/horizons/`) | [NASA/JPL Solar System Dynamics](https://ssd.jpl.nasa.gov/horizons/) | Public data. Fetched once by `scripts/fetch-horizons.mjs` under JPL's fair-use policy; the app never calls the API. |
| IAU WGCCRE 2015 rotational elements | Archinal et al. 2018, *Celest. Mech. Dyn. Astr.* 130:22 | Published values, cited in `src/astro/bodies.js`. |
| Leap seconds, ΔT | IERS Bulletin C / `Leap_Second.dat`; Espenak & Meeus (2006) polynomials via NASA GSFC | Public data. |
| Physical parameters (radii, GM, periods) | NASA NSSDC planetary fact sheets; JPL SSD `astro_par` (DE440) | Public data. |
| Reference event times (`test/fixtures/events.json`) | Derived from JPL Horizons; cross-checked against Fred Espenak's *Astropixels* almanac and in-the-sky.org | Each row carries its source URL. |
| Yale Bright Star Catalogue, 5th rev. ed. (`src/astro/data/stars.js`, 8 404 stars with V ≤ 6.5) | Hoffleit D. & Warren Jr W.H. 1991, VizieR V/50, via the [CfA Telescope Data Center](http://tdc-www.harvard.edu/catalogs/bsc5.html) | Public data (ADC/NSSDC); cite Hoffleit & Warren 1991. Generated by `scripts/build-stars.mjs`. |
| JPL Horizons geocentric Moon states, observer tables and osculating elements (`test/fixtures/horizons/moon*.json`, `observer.json`, `elements.json`, …) | [NASA/JPL Solar System Dynamics](https://ssd.jpl.nasa.gov/horizons/) | Public data, fetched once by `scripts/fetch-moon.mjs` / `scripts/fetch-observer.mjs` under JPL's fair-use policy; used only in tests. |
| Lunar theory | Meeus, *Astronomical Algorithms* 2nd ed. (1998) ch. 47 (abridged ELP-2000/82, Chapront-Touzé & Chapront) | Published tables, transcribed in `src/astro/moon.js` and verified against DE441 (10″, 19 km). |
| Nutation, apparent places, photometry, seasons | IAU 1980 nutation (Meeus ch. 22), light-time and aberration (Meeus ch. 23, 33), Mallama & Hilton 2018 planetary magnitudes (*Astronomy & Computing* 25, 10), Meeus ch. 27 | Published formulas, cited in the modules. |
| Galactic frame, star colours | Reid & Brunthaler 2004 (galactic pole/centre, J2000); Ballesteros 2012 (B−V → temperature) | Published values, cited in `src/astro/sky.js`. |

## Imagery

| Asset | Source | Licence |
|---|---|---|
| `public/textures/2k_*.jpg` (planets, Sun and **`2k_moon.jpg`**), `2k_saturn_ring_alpha.png` | [Solar System Scope texture maps](https://www.solarsystemscope.com/textures/), compiled from NASA imagery and elevation data (MESSENGER, Magellan, Blue Marble, Earth at Night, Viking, Cassini, Voyager, LRO/Clementine for the Moon) | **CC BY 4.0** — attribution is given in the app's About panel and here. |

Photographic surfaces can be switched off in Settings, in which case every body is drawn with the project's own
procedural shaders and no third-party imagery is used.
